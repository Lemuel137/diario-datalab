# Diário Datalab

Registro da construção do Datalab137, projeto de estudo guiado pelo curso de vibe coding.
Serve para conteúdo (linha do tempo, roteiro, carrossel) e para não repetir erro.

## Regra

- Uma entrada por sessão, arquivo `YYYY-MM-DD.md` na pasta `entradas/`.
- O que tentei, o erro real (texto do erro), o que aprendi, o que ia fazer errado.
- Nada de nome de prospect ou cliente sem autorização. Sem dado sensível.
- Entrada curta vale mais que ensaio: 10 min no fim da sessão.
